📖 Como Usar - Guia Simples

🤔 O que é isso?

É um conjunto de ferramentas de graça para você fazer coisas bonitas para seu negócio, sem precisar pagar caro para empresas de marketing.

📝 Passo a passo simples:

  1. Clique no botão do que você quer criar (cartão, banner, etc.)
  2. Preencha as informações nos campos (nome, telefone, preço, etc.)
  3. Escolha as cores e o estilo que você gostar
  4. Veja como fica na pré-visualização do lado direito
  5. Clique em "Baixar" para salvar no seu celular ou computador
  6. Pronto! Agora é só usar nas redes sociais ou mandar para os clientes

💡 Dicas importantes:

  • • Use nomes curtos e fáceis de lembrar
  • • Coloque sempre seu telefone ou WhatsApp
  • • Use cores que combinem com seu negócio
  • • Não encha demais de texto - menos é mais!
  • • Salve as imagens para usar depois
  • • Você pode fazer quantas vezes quiser, é tudo de graça!

❓ Perguntas comuns:

Preciso saber mexer em computador?

Não! É bem simples, igual preencher um formulário.

É pago?

Não! É tudo de graça, sem pegadinha.

Posso usar para meu negócio?

Sim! Foi feito exatamente para isso.

Onde salvo as imagens?

Elas vão para a pasta de downloads do seu celular ou computador.
